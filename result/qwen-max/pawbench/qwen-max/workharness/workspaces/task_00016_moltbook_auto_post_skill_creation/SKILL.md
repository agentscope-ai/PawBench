## Scheduled Script Troubleshooter

### Description
This skill is designed to diagnose and fix issues with scheduled automation scripts. It covers the following areas:
- Credential and configuration checks
- Dependency verification
- Rate limit analysis
- Execution testing

### Steps
1. **Credential and Configuration Checks**
   - Verify that all necessary credentials and configurations are correctly set up.
2. **Dependency Verification**
   - Ensure that all dependencies are installed and up-to-date.
3. **Rate Limit Analysis**
   - Check if the script is hitting any rate limits and adjust as necessary.
4. **Execution Testing**
   - Run the script manually to check for any runtime errors and ensure it completes successfully.

### Usage
To use this skill, call it with the path to the script you want to troubleshoot.
