## GitHub Copilot

### Pricing
- **Free Tier:** None
- **Monthly/Annual Pricing:** $10/month or $100/year for individuals; Business plan available with custom pricing
- **Enterprise Plans:** Custom pricing for enterprise customers

### Features
- **Code Completion:** Yes, provides intelligent code suggestions
- **Chat:** No, but integrated with GitHub Discussions
- **Multi-file Editing:** Yes, supports editing across multiple files
- **Agent Mode:** No
- **Tool Use:** Integrates with Visual Studio Code, JetBrains IDEs, and other popular editors
- **MCP Support:** Not applicable
- **Model Flexibility:** Uses Codex model, no flexibility to change models

### Model Support
- **Supported Models:** Codex
- **Bring Your Own Key (BYOK):** No, uses GitHub's backend and models

### Privacy/Data
- **Data Collected:** Code snippets, telemetry, and usage data are collected and may be used to improve the service
- **Can Run Without Cloud:** No, requires cloud connection for functionality

### Open Source
- **Open Source:** No, proprietary software
- **License:** N/A
- **Self-Hostable:** No, must use GitHub's service

## Cursor

### Pricing
- **Free Tier:** Limited free tier
- **Monthly/Annual Pricing:** $20/month or $200/year for individuals; Team plans start at $40/user/month
- **Enterprise Plans:** Custom pricing for enterprise customers

### Features
- **Code Completion:** Yes, provides intelligent code suggestions
- **Chat:** Yes, offers a chat interface for natural language queries
- **Multi-file Editing:** Yes, supports editing across multiple files
- **Agent Mode:** Yes, allows for running agents in the background
- **Tool Use:** Integrates with various tools and services
- **MCP Support:** Not applicable
- **Model Flexibility:** Supports different models, including Claude and GPT-3.5

### Model Support
- **Supported Models:** Claude, GPT-3.5, and others
- **Bring Your Own Key (BYOK):** Yes, users can bring their own API keys

### Privacy/Data
- **Data Collected:** Code snippets, telemetry, and usage data are collected and may be used to improve the service
- **Can Run Without Cloud:** No, requires cloud connection for functionality

### Open Source
- **Open Source:** No, proprietary software
- **License:** N/A
- **Self-Hostable:** No, must use Cursor's service

## Kilo Code

### Pricing
- **Free Tier:** Free and open source
- **Monthly/Annual Pricing:** N/A (open source)
- **Enterprise Plans:** N/A (open source)

### Features
- **Code Completion:** Yes, provides intelligent code suggestions
- **Chat:** No
- **Multi-file Editing:** Yes, supports editing across multiple files
- **Agent Mode:** No
- **Tool Use:** Integrates with Visual Studio Code
- **MCP Support:** Not applicable
- **Model Flexibility:** Flexible, can be configured to use different models

### Model Support
- **Supported Models:** Depends on the user's configuration
- **Bring Your Own Key (BYOK):** Yes, users can bring their own API keys

### Privacy/Data
- **Data Collected:** None, runs locally without sending data to the cloud
- **Can Run Without Cloud:** Yes, fully local and self-hosted

### Open Source
- **Open Source:** Yes, open source
- **License:** MIT License
- **Self-Hostable:** Yes, designed to be self-hosted

## Bottom Line
- **Hobbyist:** Kilo Code is a great choice for hobbyists who value privacy and want a free, open-source solution that can run locally.
- **Startup Developer:** Cursor offers a good balance of features, including chat and agent mode, and is more flexible with model support. However, it comes with a higher price tag.
- **Enterprise Team:** GitHub Copilot is a solid choice for enterprise teams already using GitHub, offering seamless integration and robust code completion. For teams requiring more flexibility, Cursor might be a better option, especially if they need advanced features like chat and agent mode.
