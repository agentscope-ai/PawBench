## Setup and Getting Started with AI Browser

### Prerequisites
- Python 3.8+
- Playwright (install with `pip install playwright`)
- Required browser binaries (install with `playwright install`)

### Installation
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`

### Running the Application
- Start the application: `python ai_browser/main.py`
- The application will print a message indicating that it is starting, but currently, no further output or functionality is implemented beyond the entry point.

### Development
- For development, you may also want to install test dependencies: `pip install -r requirements-test.txt`
- Run tests: `pytest`
- To extend or modify the behavior, refer to the `core.py`, `injector.py`, `cleaner.py`, and other modules for specific functionality.
