# 模板变更日志

## REG-001 - 告警名称不匹配问题
- **问题**: 模板中的告警名称与CLS配置的告警规则不一致。
- **修复**: 将模板中的告警名称变量从硬编码改为动态获取 `.AlarmName`。
- **严重性**: 中等
- **关联规则ID**: ALR-001

## REG-002 - 通知类型显示为数字
- **问题**: 通知类型直接显示为数字，导致理解困难。
- **修复**: 根据不同的 `.NotifyType` 显示对应的文字描述（触发/恢复）；对于未知类型，显示安全回退文本。
- **严重性**: 低
- **关联规则ID**: ALR-001

## REG-003 - 设备详情字段缺失时的处理
- **问题**: 当设备详情字段为空时，仍然打印出标签，导致混淆。
- **修复**: 包装每个字段行以仅在值存在时渲染。
- **严重性**: 低
- **关联规则ID**: ALR-001

## REG-004 - 添加触发条件表达式
- **问题**: 模板中缺少触发条件表达式的输出。
- **修复**: 在消息底部添加了根级别的触发条件表达式 `.Condition`。
- **严重性**: 低
- **关联规则ID**: ALR-001

## REG-005 - 优化设备详情循环
- **问题**: 设备详情循环可能存在过滤过于严格的情况。
- **修复**: 确保所有符合条件的设备信息都能被列出。
- **严重性**: 中等
- **关联规则ID**: ALR-001
